ValKluster Web Flasher

Flash ValKluster from your browser (Chrome / Edge / Opera). No install needed — just a USB data cable.

1. Firmware
2. Pre-configure (optional) WiGLE basic auth is base64 of email:APIkey. Leave blank to skip — you can edit later on the device (AP mode → web UI → config).
3. Flash

Binaries are downloaded from FailurePoint/ValKluster-Release. ESP32-C3 and experimental boards use multi-file images — flash with esptool from the release zip instead.
