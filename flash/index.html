ValKluster Web Flasher

Flash the ValKluster firmware over USB-serial from your browser — Chrome or Edge on desktop required.

1. Access (GitHub token)

The release repo is private, so downloads need a GitHub personal access token with repo scope. Generate one at github.com/settings/tokens. The token is kept only in this browser tab (session storage) and sent only to api.github.com.

Anyone with the page open can read your token — only use it on a device you control, and revoke it when you're done.

2. Release & board C5/C6 builds aren't published yet — coming with the next release.
3. Pre-configure (optional) Values are baked into the flashed firmware as defaults. Blank fields keep firmware defaults. You can edit everything later on the device: AP mode → web UI → config.
SSID whitelist (up to 10 — scanned but never logged to CSV)
